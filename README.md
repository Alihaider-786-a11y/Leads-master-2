# Leads Master Pro
Run:
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
uvicorn app:app --reload
Open http://127.0.0.1:8000

This is a professional lead-management platform starter. Connect only lawful/authorized business-data providers for automated discovery. Do not bypass CAPTCHAs, logins, paywalls, robots restrictions, or collect sensitive personal data without a lawful basis.
